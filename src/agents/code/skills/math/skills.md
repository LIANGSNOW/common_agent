# Math Skills Documentation

This document describes all available functions in `math/scripts/basic.py`.

## Functions

### `add(a: float, b: float) -> float`
Add two numbers together.

**Parameters:**
- `a` (float): First number
- `b` (float): Second number

**Returns:**
- `float`: Sum of a and b

---

### `multiply(a: float, b: float) -> float`
Multiply two numbers together.

**Parameters:**
- `a` (float): First number
- `b` (float): Second number

**Returns:**
- `float`: Product of a and b

---

### `divide(a: float, b: float) -> float`
Divide two numbers.

**Parameters:**
- `a` (float): Dividend
- `b` (float): Divisor

**Returns:**
- `float`: Quotient of a divided by b

---

### `subtract(a: float, b: float) -> float`
Subtract two numbers.

**Parameters:**
- `a` (float): First number (minuend)
- `b` (float): Second number (subtrahend)

**Returns:**
- `float`: Difference of a minus b

---

### `sin(a: float) -> float`
Take the sine of a number.

**Parameters:**
- `a` (float): Angle in radians

**Returns:**
- `float`: Sine value of the input angle

---

### `cos(a: float) -> float`
Take the cosine of a number.

**Parameters:**
- `a` (float): Angle in radians

**Returns:**
- `float`: Cosine value of the input angle

---

### `radians(a: float) -> float`
Convert degrees to radians.

**Parameters:**
- `a` (float): Angle in degrees

**Returns:**
- `float`: Angle in radians

---

### `exponentiation(a: float, b: float) -> float`
Raise one number to the power of another.

**Parameters:**
- `a` (float): Base number
- `b` (float): Exponent

**Returns:**
- `float`: Result of a raised to the power of b

---

### `sqrt(a: float) -> float`
Take the square root of a number.

**Parameters:**
- `a` (float): Number to take the square root of

**Returns:**
- `float`: Square root of the input number

---

### `ceil(a: float) -> float`
Round a number up to the nearest integer.

**Parameters:**
- `a` (float): Number to round up

**Returns:**
- `float`: Smallest integer greater than or equal to the input number
